Candle Tool

Unreal tool for scene dressing

Overview

As part of an advanced Niagara course, I learned how to use Mesh Instances inside Unreal Blueprints. I realized how useful this feature is, as it allows artists to dress scenes efficiently while reducing the number of meshes that need to be created.

I decided to apply this and create a tool that artists can use to make scene dressing easier and more optimized. At the same time, I wanted to incorporate my past knowledge in Niagara so the tool could be used in a variety of scenarios instead of simply placing meshes.

The tool allows the user to select any mesh and arrange it either in a linear or circular layout using mesh instancing. A Niagara System can also be assigned to spawn alongside each mesh, making it useful for props that require both. For this showcase, I used candles that can be displayed in either a lit or unlit state, but the tool can easily be adapted to other meshes.

Features

The tool was designed to be modular, so I added variables to set the meshes and the Niagara System that can be easily change thorugh the Blueprint settings.

Users can choose between a linear or circular arrangement. When using the circular layout, additional settings become available, such as generating a perfect circle or adding a custom offset to create a more natural and organic distribution.

My goal was to build a reusable tool that speeds up scene dressing while remaining flexible to be used in multiple projects.
