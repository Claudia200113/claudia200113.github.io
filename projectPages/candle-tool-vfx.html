Grenade VFX

A visual reinterpretation of Tracer's ultimate ability from Overwatch.

Overview

This time I decided to create a tool focused on helping populate environments procedurally inside Unreal. This tool lets you generate candles in either a linear or circular arrangement, with support for perfect circles or a custom offset to create more organic layouts. Each candle can also spawn a Niagara flame, giving it a realistic look. Designed to be modular, flexible, and easy to use. Note: This time I used lit candles as an example — but the tool can be used with any mesh and Niagara system.

After analyzing the original effect, I noticed that the anticipation phase can sometimes be easy to miss, causing enemy players to overlook the ultimate being casted and causing the gameplay feel unfair. To improve this, I included new assets such as lighting sprites, rubble meshes, and smoke particles to give the effect more visual presence and weight. Additionally, adding these elements help make the ultimate feel more powerful.

Additional Notes

For the render of the effect, I selected an environment with an art style similar to Overwatch. This allowed me to better showcase how the effect would integrate into an in-game setting and demonstrate the visual design decisions behind the textures, materials, meshes, and particle systems used throughout the project.
