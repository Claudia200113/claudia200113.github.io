Contrail VFX

A fan made version of Rocket League's Dark Matter Boost

Overview

For this project I decided to learn and work with ribbons and found one of the best examplres are Rocket League boost so I decided to try doing my own version of one. I choose the Dark Matter boost since at first galnce I did not knew how to work arround the lighting-type ribbon and the main black one. I wanted to choose a challenging effect which would make me learn new concepts, as well as being a challenge to reproduce Rocket League style and high quality bar.

Techincal Features

One of my objectives while developing the project was working on the optimization of it. I set multiple emitters in each system. This allows to reduce the cost of rendering process and calculations as they are run only once when shared.
