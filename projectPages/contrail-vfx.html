Contrail VFX

A fan made version of Fortnite´s: Portal Particles

Overview

This time I decided to take an exisiting effect from one of the most popular games, Fortnite. I decided to do this because not only it is a challenge to copy an exisitng effect and achieve the closes result posible, but I designed the effect as if it were to be used on the actual game. That is why I not only focused on the visuals of it, but focused on a clean and optimized implementation of it.

Techincal Features

One of my objectives while developing the project was working on the optimization of it. I set multiple emitters in each system. This allows to reduce the cost of rendering process and calculations as they are run only once when shared.

In the first draft of the effect, six emitters were created, but using spawning groups, arrays, and custom binding I was able to reduce the number to only three. Two for each ribbon (blue and pink) and another one which handles all the dots.
