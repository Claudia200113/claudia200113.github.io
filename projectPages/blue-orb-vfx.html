Turrent Attack Orb

Effect created to resemble a turrent and attack enemies within a range.

Overview

For this project, I wanted to combine the visual style of Ghostwire: Tokyo's Wind Weaving ability with the gameplay of one of the Warlock's abilities from Destiny, one of my favorite games.

The result was a turret ability where the player casts an orb which detects enemies within range and attacks them. My goal was not only to design and create the effect, but to program it in a way that was easy for designes to change and iterate on it.

To achieve this, I exposed certain Niagara User Parameters so values such as the turret's attack duration could be adjusted without modifying the system itself. I also programmed the complete turret behavior using Blueprints, including enemy detection, targeting, and attack logic in a way that it was easy to be changed and adapted to each project.

Challanges

One of the biggest challenges of this project was programming the turret's behavior. I wanted it to detect nearby enemies, rotate towards them, and trigger timed attacks through events. This with the visuals properly working along the programming.

Another important goal was making the ability as designer-friendly as possible. Rather than requiring changes in both the Blueprint and the Niagara System, I connected the values so designers only need to modify the variables inside of the blueprint. This makes balancing the ability much faster and allows for quick iteration.

Additional Notes

Along the orb behaviour I programmed the character animations, sequencers, and set the render for the final cinematics used for the showcase.
