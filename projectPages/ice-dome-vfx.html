Ice Doom VFX

Overview

VFX inspired by Mei's ultimate from Overwatch! This project is a reinterpretation of the ultimate ability used by Mei in Overwatch. I felt the original effect could be pushed a bit further visually so I decided to reconceptualize and add my own touch. One thing I noticed is that the anticipation of the ultimate is mostly communicated through an animation. I wanted to add anticipation to the effect itself, so I added more visual buildup so nearby players have a clearer cue of when the ultimate is being casted. For the main effect, I added interactive smoke which fades as the player enters the dome. I also implemented a distortion to help the idea that the player is inside of a blizzard. At the same time, I made sure that players outside of the dome could still see the inside so gameplay readability isn't affected. Finally, I felt the ultimate had no outro to communicate it finished, so I added a small particle burst.

Objective

I wanted to create a tool to populate scenes easily. I designed the tool to be modular, so both the mesh and Niagara used can be easily changed on the tool detail by the user.
