Candle Tool

Overview

VFX inspired by Zarya's ultimate from Overwatch! This project is a reinterpretation of the ultimate ability used by Zarya in Overwatch. I felt the original effect could be pushed a bit further visually so I decided to reconceptualize and add my own touch. One thing I noticed is that the anticipation of the effect felt a bit short compared to the weight the ultimate has in the gameplay. The address this, I added multiple elements such as rubble meshes, sprites and a subtle distortion to make easier for players to notice the explosion. For the main effect, the main change was the addition of rocks being pulled to the center. I believe this adds more visual weight to the ability, making the ultimate more noticable while supporting the idea the idea that the ultimate is so powerful it is pulling debris from the ground. Finally, I added a rubble and a particle burst at the end so players can notice when the ultimate has finished.

Objective

I wanted to create a tool to populate scenes easily. I designed the tool to be modular, so both the mesh and Niagara used can be easily changed on the tool detail by the user.
