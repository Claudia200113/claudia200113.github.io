Sword VFX

Overview

I created a tool focused on helping populate environments procedurally inside Unreal. This tool lets you generate candles in either a linear or circular arrangement, with support for perfect circles or a custom offset to create more organic layouts. Each candle can also spawn a Niagara system, giving it a realistic look.

Objective

I wanted to create a tool to populate scenes easily. I designed the tool to be modular, so both the mesh and Niagara used can be easily changed on the tool detail by the user.
