Sword VFX

Environmental effect for static sword.

Overview

While looking at different real-time VFX, I noticed a lot of environmental effects have particles spawning directly from meshes. Since I had never done anything alike, I thought it would be a fun challenge to create an effect for a sword where flames were spawned around the mesh instead of appearing randomly.

To make this happen, I had to learn how to use Niagara Scratch Pads. Since I had very little experience with them, a big part of the project was researching how they worked, watching tutorials and playing around until I was able to spawn the flames as I wanted.

I ended up creating a Scratch Pad that calculates the sword's triangles, assigns them an index, and uses that information to randomly select some of the index and spawn particles at their location. Another important factor was limiting the number of flames spawned, to keep the effect optimized.
