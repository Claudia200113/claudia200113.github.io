Stencil Buffer Shader

Stencil buffer shader programmed with HLSL in Unity.

Overview

Overview For this project, I wanted to put my HLSL skills into practice by creating a stencil shader in Unity. Since I also wanted to challenge myself and make the shader a bit more versatile, I added customizable stencil options directly to the material so it could be adapted to different use cases. Although the shader itself is relatively simple, it was a fun project that helped me become more comfortable writing HLSL code and better understand how stencil buffers work within Unity’s rendering pipeline. To make the project feel more complete, I also created a short mock gameplay video showcasing how the shader could be used in an actual game. This was a great opportunity to practice not only shader programming, but also presenting a technical feature in a way that highlights its practical use.

After an analysis, I noticed that the ultimate's anticipation was mainly communicated through an animation triggered by Mei rather than through the effect itself. Considering this, I decided to add a more visible cue so that players who are not able to see the animation, still have a clear cue of the ultimate being cast.

Another addition I implemented was a distortion effect on the dome, making it appear as a contained storm to players outside of it. Furthermore, the mist inside the dome is interactive, meaning that it fades according to the player's distace. If close enough, the mist will not render so players inside the dome can still have some visibility.

Finally, to make the ultimate fade out smoothly and still feeling powerful, I added a small particle burst at the end.

Additional Notes

For the render of the effect, I selected an environment with an art style similar to Overwatch. This allowed me to better showcase how the effect would integrate into an in-game setting and demonstrate the visual design decisions behind the textures, materials, meshes, and particle systems used throughout the project.
