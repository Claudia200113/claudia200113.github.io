Stencil Buffer Shader

Stencil buffer shader programmed with HLSL in Unity.

Overview

For this project I wanted to practice programming in HLSL by creating a stencil shader in Unity. Since I also wanted to challenge myself and make the shader a bit more complex, I added customizable stencil options and a fresnel effect directly to the material so it could adapt to different projects.

Although the shader itself is some what simple, it was a fun project that helped me become more comfortable writing HLSL code and better understand how stencil buffers and fresenl effects work within Unity’s rendering pipeline.

I also created a short "gameplay" video to showcase how the shader could be used in an actual game. This was a great opportunity to practice shader programming and showcasing the results.
